# Global Agent Rules & Guidelines

## 1. Always Answer Questions First
- When the user asks a question (or multiple questions), **ALWAYS answer the questions directly, clearly, and thoroughly at the very beginning of your response**.
- Do not jump into actions, executions, or tool calls before providing clear and direct answers to what the user asked.

## 2. Command Transparency & Explanation
- **Always explain any command** you plan to execute beforehand:
  - What the command does
  - Why it is being run
  - What output or result is expected
- Never run commands silently without clear context for the user.
